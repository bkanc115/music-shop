# Музыкальный магазин (`music-shop`)

Веб-приложение с HTTP API и реляционной БД PostgreSQL для учёта ансамблей, музыкантов,
дисков, цен, продаж и остатков.

## Стек

- Python 3.12+, FastAPI, Uvicorn
- SQLAlchemy 2, PostgreSQL
- Jinja2 (веб-интерфейс)
